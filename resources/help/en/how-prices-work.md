When you add a wine to an order, its price is worked out in this order — the first rule that applies wins:

1. **An agreed price for this customer.** If you have set a customer price for the wine, that is the price. **No rebate is applied** on top — it is already the negotiated number.
2. **A tier price.** If the customer is on a pricing tier with a fixed price for this wine, the rebate is taken off that price.
3. **The list price.** Otherwise the wine's list price is used, minus the rebate.

## Which rebate?

Rebates don't add up. The customer's **own rebate** is used if it is more than 0 %; otherwise their **tier's rebate**.

> Example: list price €18, the customer is on *Wholesale* (15 %) with no rebate of their own → €15.30. Give the customer their own 10 % rebate → €16.20.

## Setting agreed and tier prices

Both are set on the product: **Inventory** → the wine → **Pricing** tab → **Add customer price** or **Add tier price**.

Prices on an order are copied when the order is placed, so changing a price later doesn't change existing orders.
